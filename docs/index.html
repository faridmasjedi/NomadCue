Run your whole show from one GO button

NomadCue is free, open-source show control for theatre, live events and installations. Sound, projection, lights and network commands, all timed and linked together.

macOS (Apple Silicon & Intel) · Windows · Linux · MIT licence · no accounts, tiers or limits

Everything is included

There's no paid tier. Every feature below works in the download, as many times and on as many outputs as your hardware allows.

♪Audio

Unlimited outputs, per-cue crosspoint routing, fades with 5 curves, loops, EQ, compressor, delay and reverb.

▶Video & projection

Unlimited stages on any display, layering, 16 blend modes, cropping, corner-pin keystone and edge blending.

☀Lighting

DMX over Art-Net and sACN, a text command language, groups, RGB(W) and moving-head instruments.

↓Linked cues

Wait for GO, start next with this, or start next when done. Pre-waits, post-waits and groups.

⇄OSC & UDP

Control NomadCue from consoles and other software, and send OSC or plain UDP from any cue.

♫MIDI, MSC & timecode

MIDI triggers with MIDI Learn, MIDI Show Control in and out, MIDI files and MIDI timecode.

📱Phone remote

Open a web page on any phone, tablet or laptop to press GO, panic and fire cues.

{}Scripting

JavaScript script cues with a simple API for cues, lights, OSC, UDP and MIDI.

First launch

The builds aren't code-signed yet, so your system will ask you to confirm the first time you open NomadCue.

macOS

Open the .dmg and drag NomadCue to Applications. The first time, right-click the app, choose Open, then Open again. After that it opens normally.

Windows

Run the installer. If SmartScreen says "Windows protected your PC", click More info, then Run anyway.

Linux

AppImage: chmod +x NomadCue-*.AppImage and run it. Debian/Ubuntu: sudo apt install ./NomadCue-*.deb.

Build your first show

Drag sound or video files onto the window, then press Space. The quick start walks you through it.
